# Native saved-search alerts (layer 1 — no code)

Fastest, most reliable coverage: each platform emails you on new matching listings. The scout is the aggregator on top. Tip: links include a **price cap** (`_udhi`) so full-price pieces don't flood you.

## eBay (Save this search → email)
Open logged in, click **Save this search**, enable email alerts. Repeat per market.
- eBay.de Birkin: `https://www.ebay.de/sch/i.html?_nkw=hermes+birkin&_sop=10&_udhi=12000`
- eBay.de Kelly:  `https://www.ebay.de/sch/i.html?_nkw=hermes+kelly&_sop=10&_udhi=12000`
- eBay.fr / eBay.it / eBay.co.uk: same pattern.

> Do NOT use "beschädigt / as is" keywords — they return 0 results. Filter by price, not words.

## Vestiaire Collective
`https://www.vestiairecollective.com/search/?q=hermes%20kelly` → filter Hermès + Birkin/Kelly + max price → save search / bell → enable email. Switch currency to EUR and filter sellers to EU.

## Leboncoin (France, private sellers)
`https://www.leboncoin.fr/recherche?text=hermes%20birkin` → set max price → "Enregistrer la recherche" → email alerts.

## Buyee (Japan — Yahoo Auctions + Mercari JP)
Official proxy for both. `https://buyee.jp/item/search/query/エルメス%20バーキン` → Favorite (♥) → enable email notifications. (バーキン = Birkin, ケリー = Kelly, 難あり = "with a defect")
