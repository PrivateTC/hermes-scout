# Luxury Resale / Renovace — web design skill

Principy pro prémiový web v oboru luxusní resale + výkup + renovace. Cíl: působit **drahuse, důvěryhodně, řemeslně** — ne jako levný bazar.

## 1) Estetika (z čeho čerpat)
- **Hermès 2026:** ručně kreslené ilustrace, litografický nádech, lidský/řemeslný pocit (vědomě NE „AI vzhled"). Produkty si „hrají" s ilustrací. → přidej jeden autorský/řemeslný prvek (ilustrace, textura papíru, ručně psaný akcent), ať se web odliší.
- **Luxury minimalismus:** hodně bílého prostoru, klid, jeden silný prvek na obrazovku. Méně je víc.
- **Resale lídři:** The RealReal = klidný, uspořádaný, kurátorský layout + radost z objevování. Fashionphile = detailní popis stavu + bohatá fotografie + výkup. Vestiaire = důvěra přes ověření pravosti.

## 2) Paleta
- Základ: **krémová/off-white** (#faf8f5) + **uhlová/inkoust** (#1d2330) pro text a tmavé sekce.
- Akcent: **tlumené zlato/koňak** (#9c7b34) — střídmě (CTA, linky, čísla). Nikdy křiklavé barvy.
- Doplněk: jemná zelená pro „ověřeno/důvěra", neutrální šedé linky (#e7e3db).
- Pravidlo: max 1 akcentní barva + neutrály. Sytost drž nízkou.

## 3) Typografie
- **Display nadpisy: elegantní serif** (Playfair Display, Cormorant, Fraunces nebo systémové Georgia) — velké, s jistotou.
- **Text: čistý grotesk/sans** (system-ui / Inter / Helvetica) pro čitelnost.
- Velký kontrast velikostí (h1 ~40–56px), vzdušné řádkování (1.5–1.7), letter-spacing u malých uppercase labelů.

## 4) Layout
- Široké, vzdušné sekce (padding 56–80px), max-width ~1040–1240px.
- **Kurátorské mřížky** produktů (ne přeplácané), velké fotky, klid kolem.
- Editoriální bloky (story/řemeslo) střídané s katalogem.
- Mobile-first, dvousloupcové hero → stack na mobilu.

## 5) Fotografie (kritické)
- **Velké, kvalitní, konzistentní** fotky. Nejlepší = vlastní (before/after renovace). Stock jen jako placeholder + kredit.
- object-fit: cover, jemné rounded rohy (12–18px), měkký stín.
- Nikdy rozbité obrázky — vždy ověř, že se URL načte.

## 6) Důvěra (v resale rozhoduje o konverzi)
- Viditelně: **ověření pravosti** (specialista/zařízení), bezpečná platba, výkupní smlouva, recenze, fyzická adresa, diskrétnost.
- Detailní **popis stavu** + hodně fotek (jako Fashionphile). U poškozených kusů povinné.
- Trust bar hned pod hero (badge: Ověřená pravost · Bezpečná platba · Do 24 h).

## 7) Pohyb
- **Jemný, pomalý** (fade/parallax, 300–600 ms, ease). Žádné agresivní animace. Luxus = klid.

## 8) Komponenty
- Hero (claim + 1 silná fotka + CTA + trust badge).
- Trust bar. Kurátorská kolekce (karty: foto, model, cena, stav, „ověřeno"). Služby (Koupit / Prodat-výkup / Renovace). Editoriál o řemesle. Ověření pravosti. FAQ. Patička s kontaktem.
- CTA střídmě, jasné („Chci ocenit", „Prohlédnout kolekci").

## 9) Do / Don't
- ✓ Klid, prostor, serif nadpisy, tlumené zlato, ověření pravosti, vlastní fotky, řemeslný akcent.
- ✗ Křiklavé barvy, přeplácané mřížky, stocková genericita bez identity, „AI look", rozbité obrázky, slovo „bazar".
- ⚠️ Ochranná známka: „Hermès/Birkin/Kelly" nepoužívat v názvu/doméně/logu; v textu jen popisně (prodej/výkup konkrétních kusů).
